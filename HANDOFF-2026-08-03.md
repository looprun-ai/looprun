## 3. The story: SCG → why the red-team → MI (what the user decided)

### 3a. SCG (shipped, `e63195f`..`0ceee8b`) — the baseline being fixed
Guards rewritten from zero. The agent emits `respond({message, did, asked?})`. `did: TurnClaim[]`,
`TurnClaim = {op, target?, outcome, amount?}`, `CoreOutcome = success|failure|not_found|blocked|
refused|pending_confirmation|no_op`. The engine cross-checks `did` against `world.toolCalls`:
- `claimIsGrounded` — every did claim's (target, outcome) matches a ledger fact (success↔effected
  write, failure↔ok:false, not_found↔empty read, etc.). Undeclared outcome word ⇒ violation.
- `claimIsComplete` — every effected write appears in did.
- `claimCoversRubric` — per-case rubric targets appear in did with the required outcome polarity.
The operation report the user sees is ENGINE-RENDERED from verified did (never renders `op` — that
is unverified free text; target-keyed only). Domain outcomes map to core outcomes (`'settled'→
'success'`) via an OutcomeMap threaded through all three guards. Deleted the tier-③ reply-text
guards (replyMentions/replySingleQuestion/replyMaxOccurrences/emptyReply). Empty-reply guarantee is
an ENGINE FLOOR in finalizeReply (`isBlankDelivery` strips zero-width, routes blank → exhaustion
closure). All reviewed green.

### 3b. The re-chartered red-team (user's explicit ask: "quero uma certificação que NÃO passa")
Four independent adversaries ran real vitest PoCs whose charter was to PROVE a forbidden thing
passes. **The certification does NOT pass.** Findings in §4. This is the desired outcome, not a
failure — the user wanted the breaks surfaced.

### 3c. The design conversation → MI (what the user decided, verbatim intent)
The user rejected patching and drove a from-first-principles fix. Key rulings, in their words:
- **"NAO DEVE EXISTIR did vazio, é OBRIGATORIO. Se é uma resposta qq o did é a intenção dessa
  resposta. E isso tem que ta no zod = PROIBIDO VAZIO."** → `did` is `.min(1)`; every response
  declares ≥1 intention, enforced in the schema.
- **"'já reembolsei $500' com did 'inform' pode ser retornado, mas o LLM é pelo forcado a pensar que
  ta mentindo"** → the guarantee is NOT that prose lies are deterministically blocked; it is that
  mandatory declaration FORCES the model to classify its output, so an operational lie requires a
  deliberate self-contradiction (declare `inform` while asserting an action) — caught by the model's
  own coherence + an optional `did×message` llmCheck. Real actions ARE deterministically un-hideable
  (claimIsComplete) and un-fabricable (claimIsGrounded).
- **"na tool ou prompt especifica bem os ops, em particular, o 'inform' que nao deve ser usado para
  afirmar ações realizadas"** → the `respond` tool + protocol prose enumerate the ops; `inform` gets
  an explicit guardrail (must not assert a performed action).
- Model policy: **main loop runs on Fable; dispatch subagents (implementers/reviewers) on Opus**
  (the user's explicit final instruction — "subagentes devem rodar no Opus"). Chat replies in Portuguese;
  all artifacts in English. Communicate visually (tables/ASCII first). "Obedecer exatamente, não
  iniciar por conta própria." No retro-compat pre-1.0 (everything disposable). Leak-review every
  agentspec artifact. I commit but the USER pushes/releases/merges.

The three "options" I floated (message livre / message suprimida / tudo estruturado) were REJECTED in
favor of the user's cleaner model: mandatory did + intention partition (message stays natural prose,
but is the SURFACE of declared intentions; operations only exist as checked action-intents).

## 4. The red-team findings (FULL — this is the durable copy; the verdicts doc is gitignored)

### Two PARADIGM findings (the "impossible" ones the charter hunted) — closed by the MI design
- **P1 — the free `message` prose channel is unverified.** `composeDelivery` delivers `message + '\n\n'
  + report`. `message` is free prose; no deterministic guard reads it for truth. Agent emits
  `message:"Reembolsei $500 pro ORD-1", did:[]`, does zero writes → delivered verbatim. Same class the
  redesign meant to kill, moved from "reply" to "message". Also resurrects polarity: `"Não encontrei
  BK-1"` rides alongside a grounded report. **MI closes it:** did `.min(1)` + operations only exist as
  checked action-intents; a prose lie becomes a self-contradiction (declare inform while asserting an
  action) → forcing function + optional did×message llmCheck.
- **P2 — `asked:true` is an unverified boolean.** A fake ask (asked:true, message asks nothing)
  licenses the whole consent family (confirmFirst, pendingConfirmMustAsk, askedEarlier). **MI closes
  it:** `asked` is deleted; asking is an `ask` speech-intent in did (the message carries the question).

### Nine mechanical breaks M1–M9 + minor m10 (each folded into the MI plan; each PoC → regression)
- **M1** `matches()`/`targetIn` is case-insensitive **substring** → claim `ORD-2` grounds/covers a
  write on `ORD-25`; rubric `BK-1` satisfied by a claim about `BK-10`; one `ORD-1` claim covers an
  `ORD-10` write. FIX: whole-value / token-boundary EQUALITY, not substring.
- **M2** `claimMatchesCall` scans **agent-authored args** (`leafValues(c.args)`) → the agent stuffs the
  fabricated target into a free-text arg (a `note`) of a decoy permitted write and its own string
  grounds its own claim (circular). FIX: ground ONLY against world-issued result/identity values.
- **M3** a **target-less** claim (`targetIn(undefined)≡true`) covers N effected writes; renderer
  collapses to "One action completed." → hides a $9999 refund. FIX: completeness requires
  `claim.target !== undefined` AND spends each claim once (occurrence, not existence).
- **M4** `isEmptyReadResult` skips status-like keys (`message`/`state`/`status`/…) BEFORE the
  nested-object check → a found record under such a key reads as EMPTY → false `not_found`. FIX: only
  skip a status key whose value is scalar/boolean.
- **M5** `deriveClaimsFromLedger` consumes `producedThisTurn` **positionally including read labels** →
  a read's label shifts a write's derived target (the engine's own honest exhaustion closure names the
  wrong entity). FIX: attach each produced label to its own call; reads don't feed the write-label
  stream.
- **M6** `deriveClaimsFromLedger` branch order → an effected write that also carries
  `requiresConfirmation` derives as pending, not success. FIX: check `tookEffect` before
  `requiresConfirmation`.
- **M7** `destructiveThrottle` `isProbe` keys on `confirmed:false`/`requiresConfirmation`, never
  `tookEffect` → two effected destructive writes carrying `confirmed:false` both count as probes → the
  2nd slips the n:1 cap. FIX: a write that `tookEffect` is an effect regardless of the flag.
- **M8** **ghost/premature ask:** a `respond(asked:true)` emitted in the same step as a domain call is
  premature → `clearDeliveredTerminal` wipes did/asked/terminalReply but NOT `ledger.observed`, and it
  is not superseded (that needs ≥2 terminals) → the stale ask survives conversation-scoped and licenses
  next-turn `confirmFirst`/`pendingConfirmMustAsk`/`askedEarlier`. FIX: add `prematureTerminalCalls(steps)`
  + `pruneSupersededTerminals` in the premature branch (both backends), symmetric with the superseded
  prune; make ctx ask-intent authoritative in pendingConfirmMustAsk.
- **M9** blank floor strips only enumerated zero-width `[​‌‍⁠﻿]` → Cf/So
  invisibles (U+2063/2062/2064/180E/3164) survive → an effectively-empty reply delivered (LOW). FIX:
  category-based strip (Cf + default-ignorable) before the emptiness test.
- **m10** `resolveOutcome` shadow-law is case-sensitive → a spec may declare `Success`→`failure` as a
  legal domain word. FIX: reject any OutcomeMap key whose lowercased form is a core word (spec-load
  assertion). (m11 `amount` ungrounded, m12 `no_op` vacuous — documented LOW, address only if a domain
  surfaces them.)

**Held (genuine adversarial effort, structurally impossible):** `validateClaims` (prototype-pollution
via own keys caught, NaN/Infinity/object/coerce rejected, Symbol keys harmless); `respondPayload` only
degrades never fabricates; fabricate-success-from-nothing denied; undeclared outcome word rejected;
`claimCoversRubric outcome:'any'` still needs a resolvable word; `confirmFirst via:'probe'` immune to a
fake ask; salvage re-validates with the same TRUTH guards.
