# Calendar assistant — a looprun example seed

This directory is a SEED, not a generated bundle. It holds what the `agentspec` skill needs to
generate the agents, their deterministic world and their eval set — nothing that the skill would
produce itself.

## Purpose sentence

> Messaging-driven calendar management: add events from relative dates with reminders, check the schedule, reschedule and cancel — never double-book, never delete without asking.

## What it generates

1 agent: `scheduler`.

This seed carries no tool surface: the skill derives one from the purpose sentence.
