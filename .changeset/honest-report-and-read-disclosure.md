A report that hides nothing passes, and the result decides whether a disclosure is printed.

- `claimIsComplete` spends declarations against acts in either direction: a complete report passes
  in the agent's own order, and the deny for a hidden act names the tool and the word its evidence
  grounds — never a world fact.
- `disclose.after` is offered on every ok call of the turn, reads included, and the result decides
  whether it prints: a refused call states nothing, and a sentence authored for a read tool lands on
  the turn that read it — the only place the engine can speak when the reply refuses and no act runs.
- The reads an open consent question owes are forced, never asked for: a `before` slot naming a read
  that never ran triggers one forced single-tool generation before the reply is composed, through the
  same guard hooks as any call. Only a read the acting agent holds is forced, and the pass blocks
  nothing — a read that fails leaves the marker standing.
